## Problem
People forget bill due dates or run out of prepaid electricity/water/airtime
unexpectedly.

## Solution
A Mini App that tracks recurring bills, sends predictive reminders, and offers
auto top-up via MoMo — with a chatbot assistant for quick "what's due" style
questions.

## Core loop (demo, <3 min)
1. User opens app, sees upcoming bills.
2. User asks the chatbot "what bills are due this week?"
3. User pays a bill / enables auto top-up via MoMo.

## Tech stack
- Backend: Spring Boot 3, PostgreSQL
- Frontend: Angular 18
- Chatbot: Python/FastAPI
